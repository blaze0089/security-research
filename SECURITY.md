# Security policy

This repository contains public writeups of fixed issues. It is not a reporting channel for new vulnerabilities in the projects discussed.

If you find a vulnerability in Ghidra, radare2, lzfse, or another project, use that project's private security reporting process. Do not open a public issue with exploit details.

For corrections or questions about the content here, open an issue or contact [@blaze0089](https://github.com/blaze0089).
